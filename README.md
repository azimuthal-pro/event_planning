# Cynthia Wilson Signature Events

A simple Next.js website for Cynthia Wilson Signature Events.

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open http://localhost:3000 in your browser.

## Project Structure

- `app/page.tsx` - landing page content
- `app/layout.tsx` - base layout and metadata
- `app/globals.css` - global styling
