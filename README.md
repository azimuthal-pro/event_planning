# Cynthia Wilson Signature Events

A comprehensive Next.js website for Cynthia Wilson Signature Events featuring modern design and full functionality.

## Features

- **Hero Section** - Compelling introduction with statistics and call-to-actions
- **About Section** - Cynthia's story and core values with professional imagery
- **Services** - Detailed service offerings for weddings, corporate events, and private celebrations
- **Portfolio** - Visual gallery showcasing past event successes
- **Resources** - Planning guides, trends, and inspiration articles
- **Newsletter Signup** - Email capture for lead generation
- **Testimonials Carousel** - Rotating client reviews with photos
- **FAQ Section** - Answers to common planning questions
- **Vendor Partners** - Featured trusted partners and recommendations
- **Contact Form** - Comprehensive inquiry form with event details

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Styling**: CSS with CSS Variables and modern design patterns
- **Images**: Free Unsplash images for professional visuals
- **Responsive**: Mobile-first design with fluid layouts

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open http://localhost:3000 in your browser.
